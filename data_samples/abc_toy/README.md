# Toy ABC corpus

Four short Irish traditional tunes in ABC notation (public domain tune
settings). These are NOT the real EMelodyGen/TheSession corpus -- they
exist purely so tests and the Week 1 exercise have something small and
real to run the pipeline against without needing the actual multi-GB
datasets downloaded. Replace `download_emelodygen`/`download_thesession`
in `src/rtd/data/acquisition.py` to pull the real thing (see that module's
docstring for what's verified vs. still TODO).
